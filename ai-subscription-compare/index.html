API 成本節省技巧

📦

Batch API

OpenAI 與 Anthropic 均提供 Batch API，費用減半。適合非即時任務如批量分類、翻譯、資料處理等。

💾

Prompt Caching

快取輸入 Token 僅需 10% 基準價。對於重複使用相同 System Prompt 的應用，可大幅降低成本。

⚡

最低成本選擇

Google Gemini 3.8 Flash 促銷價 $0.75/$3.75 是目前最便宜的高性能模型（促銷至 2026/12，之後 $1.50/$7.50）。

市場趨勢與策略建議

📊

三家定價趨同

2026 年三家已完全趨同至相同的分層結構：免費 → ~$20 中階 → $100 (5x) → $200 (20x)。差異化已從定價轉向功能與生態系。

📢

廣告模式興起

OpenAI 在 Free 與 Go 方案加入廣告（2026.02）、Google AI Plus 也含廣告。Claude 是唯一全面無廣告的平台。

🧑‍💻

開發者工具差異

Claude 以 Claude Code 終端與 MCP 連接器領先於開發者工具；OpenAI 的 Agent 模式與 GPTs 生態系最成熟；Google 的 Workspace 整合最深。

🎬

多模態差異

Google 在 Ultra 方案包含 Veo 3.1 影片生成與 Flow Credits，多媒體創作能力最強。OpenAI 有圖片生成，Claude 專注文字與程式碼。
